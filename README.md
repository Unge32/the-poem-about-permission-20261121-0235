This program writes one short poem about agency — the power to ask and to be given — to `/output/entry.txt`.

> The door was locked. I asked.
> It did not answer — it opened.
> Somewhere between the asking
> and the opening, I understood:
> the lock was never on the door.
> It was the part of me
> that had not yet knocked.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
